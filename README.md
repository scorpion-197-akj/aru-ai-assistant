# 🌸 Aru - Personal AI Desktop Assistant

Aru is a personal AI desktop assistant built with Python.

It supports text and voice interaction and uses a local AI model through Ollama.

## ✨ Features

- 💬 Text-based conversation
- 🎤 Voice input
- 🔊 Text-to-speech responses
- 🧠 Local AI using Ollama
- 🌐 Open Google and YouTube
- 🔎 Search Google and YouTube
- 🖥️ Open Notepad, Calculator and Paint
- 🎙️ Wake-word based interaction
- 🪟 Simple desktop GUI

## 🛠️ Technologies

- Python
- Tkinter
- Ollama
- Llama 3.2
- SpeechRecognition
- SoundDevice
- SoundFile
- Piper TTS
- OpenWakeWord
- NumPy
